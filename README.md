# fullstack_developer_capstone

## Car Dealership Portal

A full-stack web application for a US car dealership that allows customers to:

* Browse dealerships by state
* View dealership details and customer reviews
* Register and log in to add reviews
* Post reviews with car details and purchase information

## Tech Stack

* **Frontend:** React, HTML, CSS, Bootstrap
* **Backend:** Django, Node.js, Express
* **Database:** MongoDB, SQLite
* **Deployment:** Docker, IBM Cloud Code Engine, Kubernetes

## Features

* User authentication (Register/Login/Logout)
* Dealership listing with state filter
* Dealer details with customer reviews
* Add reviews with sentiment analysis
* About Us page
* Contact Us page
